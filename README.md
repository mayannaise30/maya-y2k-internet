# Maya's Mini Internet ✦

Responsive Y2K-inspired personal mini-internet built with HTML, CSS and JavaScript.

## Add it to GitHub
1. Upload `index.html` to the root of your repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose branch **main** and folder **/(root)**, then click **Save**.
5. Wait for GitHub Pages to publish the site.

## Important
- Your edits are saved in local storage in the browser/device you use.
- Uploaded scrapbook photos stay in that browser; they are not uploaded to GitHub.
- Use **export my data** to download a JSON backup of your saved site content.
- The music player is visual-only: no audio and no Spotify connection.
- Add your own saved Pinterest pictures through the scrapbook upload field.
